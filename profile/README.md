## 让故事拥有自己的世界

从一个角色、一段设定开始，把每一次选择编织成可以继续探索的故事。

- **探索不同走向**：通过时间线与分支，延展角色和世界的故事。
- **整理创作素材**：把角色、世界设定与提示词编排放在同一个工作台中。
- **看清幕后过程**：让剧情正文与 Agent 工作记录各有位置，用工具与扩展丰富创作。
