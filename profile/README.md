## 角色 设定 还有下一章

Loom Studio 把角色卡、世界设定、故事分支和提示词放在一起管理。剧情正文与 Agent 的工作记录分开呈现，阅读和调试各有地方。

故事可以从已有节点分支，尝试另一种发展；Agent 也可以通过已配置的工具参与剧情编辑和世界状态更新。模型服务需要自行配置，调用时会发送本轮上下文。
