# Loom Studio

**Weave worlds, interweave stories.**

A locally hosted workspace for AI roleplay and interactive storytelling.

[Get started](https://github.com/The-LoomStudio/LoomStudio/blob/main/docs/guide/beta-release.md) · [Source code](https://github.com/The-LoomStudio/LoomStudio) · [Documentation](https://github.com/The-LoomStudio/LoomStudio/tree/main/docs) · [Report an issue](https://github.com/The-LoomStudio/LoomStudio/issues)

## Characters, settings, and the next chapter

Loom Studio brings character cards, worldbuilding, story branches, and prompt editing into one workspace. Story prose and Agent work logs have separate views, so reading the story and checking how it was generated each have their own place.

Branch from an existing story node to try a different direction, or configure Agent tools to edit the narrative and update world state. Model access requires a configured provider; each model request sends the context assembled for that turn.

## Our projects

| Project | Description |
| --- | --- |
| [Loom Studio](https://github.com/The-LoomStudio/LoomStudio) | Roleplay, story branches, prompt editing, and Agent tools. |
| [Website](https://github.com/The-LoomStudio/LoomStudio-website) | Product showcase, public documentation, and brand assets. |

| [The World](https://github.com/The-LoomStudio/LS_The_World) | An extension for story time, weather, places, and scenes. |

Loom Studio is currently in Beta. Extensions are maintained independently; see their repositories for usage and release status. Most documentation is currently in Chinese.
